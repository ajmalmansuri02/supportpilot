# Integrations

CloudNotes connects with:

- Google Calendar and Outlook Calendar: create a meeting note from any calendar event
- Slack: save a Slack message to a notebook with the "Save to CloudNotes" shortcut
- Zapier: automate actions such as creating a note from a new email
- Google Drive and Dropbox: attach files without uploading them

Connect integrations in Settings > Integrations. Integrations are available on Pro and Team plans, except the Google Calendar integration, which is available on every plan.

## API

The CloudNotes REST API is available on Team plans. Admins create API keys in Admin > API. The API is limited to 600 requests per minute per team.
