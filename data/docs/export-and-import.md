# Exporting and importing notes

## Exporting

You can export a single note or a whole notebook.

- Markdown export is available on all plans. Go to the notebook menu and select Export > Markdown. You get a ZIP file with one .md file per note and an attachments folder.
- PDF and Word (.docx) export are available on Pro and Team plans.
- To export everything at once, go to Settings > Data > Export all. We email you a download link when the export is ready, usually within 1 hour. The link is valid for 7 days.

## Importing

CloudNotes can import from Evernote (.enex files), Notion (Markdown and CSV export), Google Keep (Google Takeout) and plain Markdown folders. Go to Settings > Data > Import and choose the source. Imports of more than 5,000 notes run in the background, and we email you when they finish.
