# Sharing and team spaces

## Sharing a note

Select Share on any note to create a link. On the Free plan, links are view-only. On Pro and Team plans, you can choose view or edit access, set a password, and make the link expire after a set date. You can turn a link off at any time, which immediately stops access.

## Team spaces

Team spaces are shared folders available on the Team plan. Admins create spaces and choose who can view or edit each one. Everyone with edit access sees changes live, with each person's cursor shown in a different colour.

## Admin console

Team admins can add and remove users, reset members' 2FA, see storage use, and download an audit log of sign-ins and sharing changes for the last 90 days. Admins manage seats in Admin > Users. Adding a user is billed on a prorated basis; removing a user takes effect at the next renewal.
