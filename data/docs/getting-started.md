# Getting started

## Notes and notebooks

Everything in CloudNotes is a note. Notes live in notebooks, and notebooks can be grouped into stacks. Add tags to any note to find it across notebooks.

## Search

Search looks inside note text, titles, tags and the text in PDFs and images. Use quotes for exact phrases, and tag:name to filter by tag.

## Keyboard shortcuts

- New note: Ctrl+N (Windows) or Cmd+N (Mac)
- Search: Ctrl+K or Cmd+K
- Force sync: Ctrl+R or Cmd+R
- Toggle checklist item: Ctrl+Enter or Cmd+Enter

## Templates

Pro and Team users can save any note as a template from the note menu. CloudNotes includes templates for meeting notes, project plans and weekly reviews on every plan.
